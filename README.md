# Bulk-Attachments
Outils pour télécharger en masse les fichiers attachés de vos mails Gmail sélectionnés.

Extension Chrome (Manifest V3) : cochez des e-mails dans Gmail, cliquez sur l'icône, la popup liste leurs pièces jointes et les télécharge en archive ZIP ou en fichiers séparés, avec rangement par dossiers et index CSV. Fonctionne aussi sur une conversation ouverte ou sur toute une recherche Gmail. Accès à Gmail en lecture seule, via l'API officielle ; aucune donnée ne quitte le navigateur.
