# Bulk-Attachments
Outils pour télécharger en masse les fichiers attachés de vos mails Gmail sélectionnés.

Extension Chrome (Manifest V3) : recherche des e-mails par expéditeur, période, libellé ou extension de fichier, sélection des pièces jointes, puis téléchargement en archive ZIP ou en fichiers séparés, avec rangement par dossiers et index CSV. Accès à Gmail en lecture seule, via l'API officielle ; aucune donnée ne quitte le navigateur.

Installation, configuration OAuth, utilisation et tests : [docs/README.md](docs/README.md).
